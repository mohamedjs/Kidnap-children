# Kidnap-children — agent entrypoint

A platform for reports of missing children and of children who were found: reports with
photos, automatic matching, search, comments, likes, private messages, notifications and
moderation. Working product name: **أنا فين؟ / Ana Fein?**

- `backend/` — Python 3.12 **FastAPI modular monolith**: PostgreSQL (SQLAlchemy 2 + Alembic),
  S3-compatible storage with presigned URLs, transactional outbox + worker process.
- `web/` — **Vue 3 + Vite**, presentation only, Arabic-first RTL.
- `site/` — product landing page (GitHub Pages, `.github/workflows/pages.yml`).
- `legacy/v1-laravel/` — the v1 Laravel + Vue 2 + Python AI app, unchanged (also tag `v1-laravel`).

Read [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) and [`docs/INVENTORY.md`](docs/INVENTORY.md).

## Rules

1. Business rules live in `backend/app/modules/<module>/domain/` as pure Python and are unit-tested.
2. A module is reached only through its `__init__.py` public API (`__all__`). Only `infrastructure/` imports SQLAlchemy / boto3 / httpx / OpenCV. `tests/test_architecture.py` enforces it.
3. Cross-module side effects: domain event → outbox → worker handler. No direct calls for side effects.
4. Files never pass through the api: presigned PUT → confirm (HEAD-checked) → claim; reads mint presigned GET URLs per response. Never store URLs; never make the bucket public.
5. Web: no data access except `/api/*`; every string through `t(key)` with `ar` and `en`; logical CSS only (`margin-inline-*`, `inset-inline-*`, `text-align: start`…).
6. Sensitive domain: seeds, tests, screenshots and the site use invented names and generated silhouettes only. Never real children's data.
7. No secrets in git: `.env` is generated by `scripts/gen-dev-env.py` and gitignored.

## Commands

```bash
python3 scripts/gen-dev-env.py && docker compose up -d     # postgres :5435, s3 :9010
scripts/dev.sh                                             # migrate, bucket, api :4100, worker, web :3100
cd backend && .venv/bin/python -m scripts.seed --reset     # demo data
cd backend && .venv/bin/pytest && .venv/bin/mypy && .venv/bin/ruff check app
cd backend && .venv/bin/python -m scripts.smoke            # 19 end-to-end API/bucket checks
cd web && npm run build && node scripts/e2e.mjs ../.data/e2e-photo.jpg
cd web && node scripts/screenshots.mjs                     # refresh site/assets/screens
```
